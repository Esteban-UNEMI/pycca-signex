# PYCCA · SIGNEX · Prototipo académico

Proyecto universitario con propósitos académicos. Catálogo, pagos, inventario, perfiles y roles de demostración; los datos se guardan en el navegador. No introducir información personal real.

Sitio público: https://pycca.jauntygoby64.chatgpt.site

La aplicación usa Next.js App Router, React y TypeScript. Para ejecutarla localmente: `npm install` y `npm run dev`. El panel `/admin`, catálogo, checkout, inventario y pagos son demostraciones; Supabase aún requiere configurar un proyecto y variables de entorno. Lee [la documentación del proyecto](docs/publicacion.md) y [las migraciones](supabase/migrations/README.md) antes de conectar servicios.

Este repositorio conserva el código fuente y las migraciones SQL preparadas; no incluye credenciales.
